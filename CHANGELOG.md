# Changelog

## [0.3.0] - 2026-11-02

- Languages show as a ring of petals behind the pink ones, shared out by code
  share, and as a striped band around the pot. Flower centers are gold again.

## [0.2.0] - 2026-11-02

- Petals are pink on every repository; languages color the flower centers.
- More commits grow more flowers, up to five in the pot.

## [0.1.0] - 2026-11-02

- First version: a potted flower grown from one repository's commits and
  languages, with five daily moods, shipped as a GitHub Action.
